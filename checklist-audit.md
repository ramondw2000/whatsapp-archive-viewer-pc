## Summary — actual gaps found (documented as a feature, not there yet)

Everything above marked ✅ is implemented and can be checked off without re-testing from scratch
(though obviously still worth a quick sanity check). The real gaps, in order of how likely you are
to notice them:

1. **Shift-click range selection in multi-select mode is entirely missing.** No shift-key handling exists.
2. **Clicking a plain text message in multi-select mode doesn't select it** — only clicking image/video/GIF content toggles selection; text bubbles no-op their click handler while in multi-select mode.
3. **There's no right-click/context menu for editing messages** — the checklist describes a context-menu-based editing flow, but the actual UI uses a hover-revealed pencil icon instead, and it's only on media messages.
4. **There's no "set a display name for a sender" feature** — nothing lets you rename a sender and have it replace their name throughout the chat. The closest existing features are (a) renaming a single media file's display name, and (b) the Username dialog, which only marks which existing sender is "you" — neither does a chat-wide sender rename.
5. **New-import auto-open only works when no chat is currently open** — if you already have a chat open and import another, the app doesn't switch you to the new one.

Per your instructions, none of these were implemented — this file is just the findings.
